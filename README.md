# Stash Extract Scraper

Stash metadata scraper for the stash-extract-db bridge service.

Part of the [stash-extract-db](https://github.com/smegmarip/stash-extract-db) project — see that repository for the backing service, documentation, and issue tracking.

## Install

Add the source index `https://smegmarip.github.io/stash-plugin-repository/main/scrapers/index.yml` under **Settings > Metadata Providers** in Stash, then install **Stash Extract Scraper**.
